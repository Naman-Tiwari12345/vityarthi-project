# Student Expense & Budget Management System

## Overview
A Python-based console application designed to help students record, manage and analyze their daily expenses.

## Features
- User registration and login
- Add expenses
- View expenses
- Delete expenses
- Set monthly budget
- Check budget status
- Category-wise spending analysis
- Expense report generation
- JSON file storage
- Input validation and error handling
- Unit testing

## Technologies
- Python 3
- JSON
- unittest
- VS Code
- Git/GitHub

## Project Structure
- `main.py` - main application
- `user.py` - registration and login
- `expenses.py` - expense operations
- `budget.py` - budget operations
- `reports.py` - analytics and reports
- `storage.py` - JSON data storage
- `validation.py` - input validation
- `utils.py` - utility functions
- `test_project.py` - tests
- `data/expenses.json` - application data

## How to Run
1. Install Python 3.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:
   `python main.py`

## Testing
Run:
`python -m unittest test_project.py`
